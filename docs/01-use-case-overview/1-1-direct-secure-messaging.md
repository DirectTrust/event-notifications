# 1.1 Direct Secure Messaging

Direct Secure Messaging, commonly called Direct messaging, Direct exchange or Direct for short, is a payload-agnostic mechanism for secure communication of health data between two known end points and can support virtually any file attachment. Direct messaging supports a wide range of use cases today including (but not limited to):

- Transitions of Care

- Referrals

- Case Reporting to Public Health

- Provider/Payer Communications

- Provider/Patient Communications

- Communication with Social and Support Services Providers
