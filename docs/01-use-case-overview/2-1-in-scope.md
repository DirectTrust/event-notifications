# 2.1 In Scope

- Specify how [The Direct Standard®](https://directtrust.org/standards/the-direct-standard/versions) will be utilized to support transport and message delivery of Unsolicited Notifications.

- Define required Context elements that allow Recipient Systems to appropriately incorporate messages into their workflows.

- Define usage of existing Context standards to convey required Metadata elements.

- Identify required Message Content Payloads including machine and human readable Event Notification information.

- Identify required and conditionally required data elements within the required Message Content Payloads.

- Recommended functional behavior for both sending and receiving Edge system Actors.
