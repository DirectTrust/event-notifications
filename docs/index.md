This guide describes a method to communicate patient Event Notifications, such as admissions, discharges and transfers, using Direct Secure Messaging. It is an implementation compliant with the [DirectTrust Metadata and Payloads Framework](https://directtrust.github.io/metadata-and-payloads-guide/).

Start with the [Overview](/01-overview/) and [Scope](/02-scope/), then see the [Use Cases](/03-use-cases/) and the [Messaging Requirements](/04-messaging-requirements/). Value sets and examples are in [Value Sets and Examples](/05-value-sets-and-examples/). Legal notices, the consensus body and the change log are under [About this Guide](/00-about-this-document/).
