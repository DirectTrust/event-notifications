# 4 Messaging Requirements

Unsolicited notification messages SHALL comply with specifications established by [The Direct Standard®](https://directtrust.org/standards/the-direct-standard/versions) and [the Context IG](https://directtrust.org/standards/the-direct-standard/context-versions). Additionally, this IG extends the context fields supported for expressing context in unsolicited notification messages.

The table shown in Section [5.4](/05-value-sets-and-examples/5-4-data-elements-in-the-message-payload#data-elements-in-the-message-payload) identifies key data elements relevant to the message metadata and payload and indicates the requirement for each data element to be included in the context/metadata, the discrete message data carried in V2 format, or the human readable content of the message. The table also points out which data elements are required to meet the CMS conditions of participation with respect to sharing ADT event notifications. Elements not listed in this IG that MAY be included at the sender's discretion are outside the scope of this IG.
